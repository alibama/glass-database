    № 01 Collecting Events

    Create and run a collecting event.

    A collecting event is a themed call for makers: pumpkins in October, ornaments in December. Makers enter pieces they have already published, collectors check a piece to add it to their collection, signed-in visitors vote. The public page is /games.html; entries and collection requests that need a look are in the Review queue.
