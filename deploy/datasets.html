    № 01 Tables

    Every table, row by row.

    The registry is a set of tables, one per sheet that was ever imported plus the ones the site fills itself. Pick one, read it, fix a cell, add a row, or import a sheet. Everything you change here is published at once, through the same gate as everything else; a row that should not be public is rejected, never deleted.
