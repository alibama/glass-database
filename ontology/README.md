# Glassblowing ontology (gbo:)

A vocabulary for describing glass objects, techniques, and provenance events —
the semantic backbone the object manifests link into. Base IRI
`http://example.org/glassblowing#` (prefix `gbo:`). It bridges existing work
(GlasDigital, the De Boer CIDOC-CRM model) so events map cleanly onto
cultural-heritage standards.

## Files

| File | Format | Use |
|---|---|---|
| `glassblowing.ttl` | Turtle | primary, human-readable source |
| `glassblowing.owl` | RDF/XML | for OWL tools / Protégé |
| `glassblowing.jsonld` | JSON-LD | for web / linked-data pipelines |
| `glassblowing-examples.ttl` | Turtle | worked examples |
| `glassblowing-ontology.md` | Markdown | narrative documentation |

Glowtbook's provenance manifests carry `gbo:` IRIs on technique assertions, so a
condensed public rendition stays semantically linkable.
